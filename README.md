# 村镇便民点水费代缴系统

按户号、账期和应缴金额代居民收取水费，出具收据并记录现金或电子支付渠道；
居民可查询本户账单与已缴凭证，操作员每日交班核对实收。

- **仅依赖 Python 3.11 标准库**（含 SQLite），无需安装任何第三方包。
- 账务事件保存在 SQLite（追加式流水，不删除）；演示收据落地为本地文本文件。
- 水务销账与支付渠道回执均为**模拟适配器**，可模拟回执延迟、失败、重复送达。

## 页面

- **账单查询**（`/`）：户号查账单、已缴凭证与冲正记录；处理延迟回执；
- **代缴**（`/pay`）：户号、户名代号、账期、应缴金额在**确认区固定**，
  前后端均不接受手改金额；可选现金 / 支付宝 / 微信 / 银行代收，并选模拟回执场景；
- **收据**（`/receipt?no=`）：本地文本收据，作废原单盖作废章并链到红字单，文件不删除；
- **冲正申请**（`/reversal`）：引用原收款流水，选原因（输错户号 / 重复缴费 /
  跨账期付款 / 回执异常 / 其他）并写明情况，提交主管；
- **冲正审批**（`/approvals`、`/approval?id=`）：主管批准/驳回；详情页
  **原单与更正单并列**、原收据与红字收据并列；
- **交班对账**（`/shifts`）：备用金 + 现金收款 − 现金冲正退回 = 应存现金；
  实点不符自动登记有符号短款/长款事件，结班后数字封存。

白底深蓝配色；负数一律同时以**符号与中文文字**说明，如
`-¥46.00（负数：肆拾陆元整）`。

## 关键业务规则

1. **流水只追加**：更正只能新增等额负向 `REVERSAL` 事件，绝不删除原流水/收据。
2. **冲正必须引用原交易且经主管批准**：`related_txn` 指向原单，
   `approval_requests` 留审批人、意见、时间；驳回后可再次申请，批准后不可二次冲正。
3. **并发不超收**：缴费在 `BEGIN IMMEDIATE` 事务内重算待缴，
   同一账单两个并发支付恰好一笔成功，应收不变负。
4. **回执幂等**：渠道流水号 `pay_ref` 数据库唯一；重复回执只确认一次、只出一张收据。
5. **失败/延迟不占额度**：`PENDING`、`FAILED` 支付不核减应收；回执到达再补开收据。
6. **站点隔离**：所有查询与操作按操作员所属 `site_id` 过滤，
   操作员只能看到本服务点现金记录、本人班次；跨站审批同样禁止。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

30 个用例，重点覆盖：

- `test_duplicate_receipt.py`：重复回执幂等、pay_ref 唯一索引、已结清拒缴、失败单不占额度；
- `test_concurrent_payment.py`：2 线程 / 8 线程并发缴同一账单，恰一笔成功、应收为 0 不为负；
- `test_reversal_balance.py`：原单 + 红字单净额为零、收据作废链、
  非主管/跨站不得审批、不可重复冲正、电子退款流水、销账延迟期间禁冲正；
- `test_site_isolation.py`：账单/缴费/现金/班次/审批/凭证六类跨站访问全部拒绝；
- `test_shift.py`：正常平衡、短款有符号事件与账实勾稽、现金冲正减应存、
  电子不入现金抽屉、回执未到禁交班、结班后金额封存；
- `test_money.py`：整数分运算、中文大写、负数符号+文字双说明。

## 目录结构

```
app.py                  启动入口（python3 app.py）
water/
  db.py                 SQLite schema（sites/operators/households/bills/ledger/receipts/...）
  money.py              金额：整数分、中文大写、负数双说明
  adapters.py           模拟支付渠道 + 水务销账适配器（延迟/失败/重复）
  receipts.py           收据渲染与本地文件（NORMAL/REDLINE，作废链）
  service.py            全部业务规则（缴费/回执/冲正审批/交班/隔离）
  seed.py               演示种子（错户冲正、短款、回执延迟样例）
web/
  server.py             标准库 http.server Web 应用（每线程独立 DB 连接）
  style.css             白底深蓝样式
tests/                  单元与并发测试
data/                   运行生成：water.db、receipts/、gateway_script.json
```
