# 村镇便民水费代缴与冲正对账系统

零依赖（仅 Python 3.10+ 标准库）：SQLite 保存账务事件，本地 HTML 文件保存演示收据，
支付渠道与水务销账均为内存模拟适配器。

## 一条命令启动

```bash
./run.sh            # 默认 http://127.0.0.1:8000
./run.sh 8010       # 指定端口
./run.sh --reset    # 清空 data/ 后重建演示数据
```

或：`python3 -m app.seed --serve`。

## 内置异常样例

1. **输错户号冲正链**：H1001 的 2026-08 现金收据已标记作废，原单（+32.00）
   与主管批准的更正单（−32.00，负数文字说明）并列；随后已向正确户 H1002 重收。
   在「现金记录」或收据页可追溯 `reverses_id` 引用。
2. **待批冲正**：H2001 2026-08（疑似重复缴费，收据待作废）——主管在「冲正审批」批准/驳回。
3. **现金短款**：张三上一班次实点比系统少 10.00 元，已生成负数 `SHORTAGE` 事件。
4. **支付成功但回执延迟**：H3001 2026-08 电子支付 `PENDING`；
   H2001 2026-07 水务回执缺失。主管页点「轮询补登」即可补登，重复回执幂等。
5. **站点隔离**：青石操作员查不到 H3001/梧岗的任何现金记录，也不能为其收款。

## 关键业务规则实现

- **只追加事件流**（`ledger_events`）：缴款、零金额到账/水务确认、冲正（负）、短款（负）。
  任何更正都**不删除、不改写流水**；已打印收据冲正时置 `receipt_status=VOID`，行仍保留。
- **冲正**：必须先由经办人发起申请（填原因）→ **主管批准**后才生成负数冲正事件，
  事件带 `reverses_id` 引用原交易、`approved_by` 记录批准人；驳回不产生事件；
  已冲正交易不能二次冲正。
- **并发付款不使应收为负**：收款在 `BEGIN IMMEDIATE` 事务内汇总该账单
  缴款+冲正（PENDING 在途支付先占额度），第二笔并发缴款拿锁后必然看到已缴清而拒绝。
- **重复回执幂等**：支付适配器按 `pay_ref` 去重；确认事件按 `(confirms_id, kind)`
  幂等插入，重复轮询不产生第二条。
- **金额强校验**：确认区固定户号/户名代号/账期/应缴金额；实收必须等于应缴，
  错户号、跨账期、非本站点户、错金额一律拒绝。
- **站点隔离**：操作员查询现金记录被 SQL 强制加 `site_code=本站`，
  强传其他站点参数直接抛 `AuthzError`（HTTP 400）。
- **交班**：现金缴款−现金冲正确认应收，实点少于应收生成负数短款事件，
  不允许改流水抹平；电子支付不计入现金抽屉。
- **负数展示**：所有界面同时给出符号（−）与文字（冲减/短款）。

## 页面

- `/` 账单查询（居民可用）：应缴、已缴净额、状态、已缴凭证与冲正链
- `/pay` 代缴：固定确认区 + 现金/电子渠道 + 延迟回执模拟开关
- `/receipt/<事件id>` 原单与更正单并列，可发起冲正申请
- `/reversals` 主管审批、延迟回执一键补登
- `/shift` 操作员开班/交班核对；主管看班次总览
- `/cash` 现金记录（操作员限本站点，主管可跨站点筛选）

演示收据文件：`data/receipts/RCP-*.html`（冲正批准后重写为原单+更正单并列）。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

- `tests/test_accounting.py`（17 项）：错户号/跨账期/金额不符、
  重复支付回执与水务回执幂等、延迟到账补登、**同账单两线程并发付款恰一笔成功**、
  **冲正引用+审批+借贷平衡（+1000/−1000 净额为零且原行保留）**、
  驳回/二次冲正、现金短款负数事件、**站点隔离**。
- `tests/test_web.py`（4 项）：真实 HTTP 会话覆盖确认区、收款、重复缴费、
  冲正申请→主管批准→并列更正单、越权 400、主管跨站点。

## 代码结构

```
app/db.py         SQLite schema（sites/users/households/bills/ledger_events/
                  reversal_requests/shifts）与连接
app/adapters.py   PaymentAdapter / WaterAdapter（幂等、可注入延迟）
app/services.py   账务服务层：查询/代缴/补登/冲正审批/交班/隔离
app/receipts.py   本地演示收据 HTML（原单+更正单并列）
app/templates.py  页面模板（白底深蓝）
app/web.py        http.server 路由、会话签名 cookie、每线程独立 DB 连接
app/seed.py       演示种子与一键启动
run.sh            一条命令
tests/            21 项测试
```
